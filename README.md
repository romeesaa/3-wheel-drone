# 3-wheel-drone
made with onshape and its just a cute drone design i made to learn cad !! almost all drones i have seen have 4 wheels and that made me  wonder why??? (idk prolly some physics stuff meh).
i dont think this has any practical use and i do plan to make a better model soon and bring that to life!!

##Description 

took 15 or 20 minutes to design. 
I got to learn about a lot of stuff such as assembly, changing the colors,extrude,sketch,loft,chamfer,circular pattern and transform tool
working with different planes to make the propeller which did confuse me quite long time since i kept working on the same plane but yeah figured it out eventually.
it took alot of effort in the start but eventually i got a hang of it yay.
